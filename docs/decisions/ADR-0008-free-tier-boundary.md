# ADR-0008: 無料範囲は第1章のまま動かさない(差別化を含まないと知った上で)

日付: 2026-09-03
ステータス: 採用

## 背景

課金ゲート(`docs/plans/paywall-gate.md`)を設計する過程で、要件7章が定める
「第1章まで無料、第2章以降はサブスク」の境界に、**設計時には見えていなかった性質**が
2つあることが分かった。

1. **無料体験は実質「約4日」で終わる。**
   第1章は会話文10本・新出漢字10字。1日3字の上限(ADR-0003)があるので、
   最短4日で無料分を使い切る。要件7章は「第1章まるごと無料が実質のトライアルとして
   機能する」ため無料トライアルを設定しないとしているが、その「まるごと」は4日ぶんしかない。

2. **「読みが変わった」演出が無料範囲に1つも無い。**
   `reencounters` を持つ会話文は58本中8本で、**最初が #17(第2章)**。
   要件4.6 の演出と、要件3.2「漢字は意味の核である」という感覚を育てる段階的再登場は、
   このアプリの**最大の差別化**(要件5.1-5 / 3.3)。
   にもかかわらず、無料の学習者はそれを**一度も見ないまま**課金画面に当たる。

つまり「価値を体験させてから課金できる」という要件7章の狙いが、
**体験させたい当の価値の手前に境界が引かれている**。

## 決定

**MVP では境界を動かさない。** 第1章までを無料、第2章以降を有料のまま実装する。

代わりに、**課金画面のコピーで「この先に何があるか」を言葉で予告する**。
`src/features/paywall/components/paywall-view.tsx` の
`Watch a kanji you know change its reading in a new scene` がそれにあたる。

**この判断は保留であって結論ではない。** TestFlight の反応を見て再検討するため、
`docs/requirements.md` 9章の未決定事項に「無料範囲の境界を見直すか」を積んである。

## 理由

- **境界の変更は要件7章の改訂であり、課金ゲートの実装とは別の判断。**
  実装の途中で仕様の根拠(どこまで無料か)を書き換えると、
  「実装しやすいから仕様が動いた」という順序になる。要件が実装に従属してはいけない
- **残り時間が短い。** 2026-09-03 時点でリリース期限は 9/30、要件8章の機能凍結目安は9月上旬。
  境界を動かすと `isFree` のデータ、`validate:content` の検証ルール、
  コンテンツ側の章構成の見直しが連鎖する。**課金ゲートが存在しないことのほうが重い**
  (`docs/release-checklist.md` で「提出できない/審査で落ちる」に分類されている)
- **転換率は実測しないと分からない。** 「差別化を見せないと売れない」も
  「先が見えるほうが気になる」も、どちらも仮説の域を出ない。
  推測で境界を動かすより、出してから測るほうが安い

## 却下した選択肢

- **第2章の途中(#17 の直後)まで無料にする。**
  演出を1回見せてから課金できるので狙いには最も忠実。却下したのは、
  **無料と有料の境界が章の切れ目からずれる**ため。要件7章は
  「章の切れ目と一致させることで導線が自然になる」と明記しており、
  ずらすと「第2章の途中まで読めるが続きは有料」という説明しにくい状態になる。
  `isFree` の「第1章の文だけ true」という不変条件も崩れ、`validate:content` の
  検証ルールごと書き換えになる
- **第1章に「読みが変わった」演出を1つ足す。**
  コンテンツ側で解く案。却下したのは、第1章は新出漢字10字を導入する章であり、
  **既習の字が再登場する余地がそもそも無い**ため(1文目の字を10文目で再登場させると、
  導入から数日しか経っておらず「読みが変わって驚く」体験にならない)。
  段階的再登場は章をまたぐ時間があって初めて効く
- **無料トライアル(7日間)を設定する。**
  却下したのは要件7章が明示的に不採用としているため。
  ここを覆すなら、それ自体が別の ADR に値する判断になる

## 結果として受け入れるトレードオフ

- **転換率が課金画面のコピー頼みになる。** 見せられない価値を言葉で説明することになり、
  「読みが変わる」体験の強さは伝わらない
- **無料の4日間で伝わるのは「会話文の中で漢字に出会う」までで、
  「学んだ字が別の場面で返ってくる」までは伝わらない。**
  要件3.1 のコア仮説のうち、検証できるのは前半だけになる
- **この判断が間違っていた場合、分かるのは TestFlight 以降。** 境界を後から動かすのは
  `isFree` のデータ変更で済むが、既に購読した人との公平性の説明が必要になる
