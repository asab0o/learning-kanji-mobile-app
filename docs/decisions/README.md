# 意思決定ログ (ADR)

「なぜこうなっているのか」を残す場所。後から自分やAIが設計を疑ったときに、
議論をやり直さずに済むようにするためのもの。

## 書くべきとき

- 要件定義書の内容を変更したとき
- 技術選定をしたとき / 一度決めたものを覆したとき
- 「一見おかしいが理由があってこうしている」コードを書いたとき

## 書かなくてよいとき

- 要件定義書にすでに理由が書いてあること(そちらを参照すればよい)
- 実装の細部

## フォーマット

`ADR-<連番>-<短いスラッグ>.md`

```markdown
# ADR-0001: タイトル

日付: YYYY-MM-DD
ステータス: 採用 | 却下 | 置き換え済み(→ADR-XXXX)

## 背景
## 決定
## 理由
## 却下した選択肢
## 結果として受け入れるトレードオフ
```
