# 対象漢字リスト(MVP用 50字)

最終更新: 2026-08-03

## 選定方針

1. **母集団**: JLPT N5範囲(約80字)から選ぶ → 実用性を担保
2. **絞り込み(最重要)**: 訓読み/音読みの対比が作れる字を優先 → 差別化の核(第2段階の演出・漢字の樹)が確実に機能する
3. **並び順**: ホームステイの日常シーンで自然に出る順 → 会話文が書きやすく、世界観と一貫する

**品詞バランス**: 動詞やや多め(動詞6:名詞4程度)＋形容詞を少し。動詞は派生で単語が広がりやすく、会話文も成立させやすいため。

**除外した字の例**: 猫・耳・足・犬など。N5頻出だが訓読みのみで広がりが作れず、主機能が空振りするため。

## イラストSUBJECT の読み方

`画風プロンプト定義.md` §2 のベースプロンプトの `{{SUBJECT}}` にそのまま入れる文字列。

- `{{MIA}}` は `a girl with short brown hair and a plain simple top` の略。生成時はこの文字列に展開する(§2 の固定書き出し。毎回同じ語で書く)

- `{{MIA}}` が無い行は **人物なしカット → Omni Reference を外す**(付けたままだと余計な人物が紛れる)

- 空・天・月・雨・水 のように**空や水面そのものが画面を占める行**は、そのまま出すと端が白へにじんで切り抜けない。枠線で囲うか `--no background gradient, colored sky wash` を足す(`画風プロンプト定義.md` §7「切り抜きが通る絵の条件」)

## 章構成と出題順

**1文=新出1字**のため、**章の字数＝その章の文数**。1日5字が上限なので、全50字は約10日で完走する想定。

> **2026-08-30 修正**: 第2〜4章の表は、順序も第2段階の欄も `docs/会話文集.md` と食い違っていた
> (例: 旧表の第2章は 月→水→火… だが、実際の会話文は 早→時→間… で書かれている。
> 第2段階の欄には #21 一人・#22 大人・火曜日・木曜日・散歩・空気・火山・買い物・会社 など、
> **会話文集に存在しない回**が並んでいた)。
> **出題順と第2段階の配置は `docs/会話文集.md` が正**なので、そちらに合わせて全面的に書き直した。
> 第2段階の8回は `docs/content-decisions.md` 5章(flow)の設計とも**1件も違わずに一致する**。
> 「文」列は対応する会話文の番号で、`1文=新出1字` の対応を目で追えるようにしてある。

**第1章を10字にしている理由**: 課金の境界(最初の10文まで無料)と章の切れ目を一致させ、「1章分まるごと無料で体験 → 続きはサブスク」という自然な導線にするため。

## 第2段階(読みが変わる)の配置ルール

1. **訓読みを先、音読みを後**(必ずこの順)
2. **同じ章内では出さない**。最低1章分の間隔を空ける
   - **第4章の4回(45・48・51・55)はこの例外。** 17文に新出13字＋第2段階4回を詰め込むため
     構造的に避けられない。経緯と補い方は `docs/content-decisions.md` 5章
3. 熟語の**もう一方の漢字も既習であること**が望ましい(演出時に「読みが変わったこと」だけに集中させるため)
   - 両方既習で組める例: 大学、学生、外国、日本、時間、人間、来年、新聞、火山、外国人
   - 片方のみ既習の例(推測クイズには使えるが、第2段階の演出には使わない): 空港、電話、銀行

**特記: 「本」の扱い**
44番の「本」は訓読み(もと)がほぼ使われず、実質「ほん」「にほん」の音読みのみ。訓→音の対比ではなく「音読み同士で意味が変わる」パターンになるため、**演出の仕方を他の字とは変える必要がある**。

## illustrationKey 対応表

漢字イラストのファイル名は**漢字ではなく英語スラッグ**(`illustrationKey`)。
日本語ファイル名を避けるためで、訓読みのローマ字も使わない
(`日`(ひ) と `火`(ひ) が衝突し、`大`(おお → ō)が非ASCIIになる)。
規約は `docs/architecture.md`「アセット」、正のデータは `src/content/index.ts` の
`KanjiEntry.illustrationKey`。

**この表は手で保守しない。** `src/content/index.ts` を変えたら次で貼り直す:

```
uv run --project scripts/illustration-cutout \
  scripts/illustration-cutout/cutout.py --list
```
