# 対象漢字リスト(MVP用 50字)

最終更新: 2026-08-03

## 選定方針

1. **母集団**: JLPT N5範囲(約80字)から選ぶ → 実用性を担保
2. **絞り込み(最重要)**: 訓読み/音読みの対比が作れる字を優先 → 差別化の核(第2段階の演出・漢字の樹)が確実に機能する
3. **並び順**: ホームステイの日常シーンで自然に出る順 → 会話文が書きやすく、世界観と一貫する

**品詞バランス**: 動詞やや多め(動詞6:名詞4程度)＋形容詞を少し。動詞は派生で単語が広がりやすく、会話文も成立させやすいため。

**除外した字の例**: 猫・耳・足・犬など。N5頻出だが訓読みのみで広がりが作れず、主機能が空振りするため。

## 章構成と出題順

**1文=新出1字**のため、**章の字数＝その章の文数**。1日5字が上限なので、全50字は約10日で完走する想定。

**第1章を10字にしている理由**: 課金の境界(最初の10文まで無料)と章の切れ目を一致させ、「1章分まるごと無料で体験 → 続きはサブスク」という自然な導線にするため。

## 第2段階(読みが変わる)の配置ルール

1. **訓読みを先、音読みを後**(必ずこの順)
2. **同じ章内では出さない**。最低1章分の間隔を空ける
3. 熟語の**もう一方の漢字も既習であること**が望ましい(演出時に「読みが変わったこと」だけに集中させるため)
   - 両方既習で組める例: 大学、学生、外国、日本、時間、人間、来年、新聞、火山、外国人
   - 片方のみ既習の例(推測クイズには使えるが、第2段階の演出には使わない): 空港、電話、銀行

**特記: 「本」の扱い**
44番の「本」は訓読み(もと)がほぼ使われず、実質「ほん」「にほん」の音読みのみ。訓→音の対比ではなく「音読み同士で意味が変わる」パターンになるため、**演出の仕方を他の字とは変える必要がある**。
