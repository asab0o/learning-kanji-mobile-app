**判断したこと(git から読めないもの)**

**既知の借りの棚卸し**

- **`話`(はなし) の葉が null という借りは、前提が誤っていた。** #25 に出るのは動詞の `話す` で、
  その葉は既に #25 を指している。名詞の `話` は41文のどこにも出ておらず、
  **つぼみのままが正しい**。データ修正は不要 → この借りは閉じてよい
- **`来` の訓 `く` と導入回 #39 の `き` の食い違いは、触らないと決めた。**
  `く` は `来る` の辞書形の読みとして正しく、`readings` の先頭の訓読みを
  `revealFor()` が「変わる前の読み」に使うため、増やす/変えると演出が壊れる。
  `き` と `く` の橋を架けるなら「読みの横に代表語を出す」形になり、それは樹の担当
