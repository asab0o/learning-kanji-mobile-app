# 会話文 決定事項一覧

最終更新: 2026-08-03
対象: 会話文集.md(v0.2)の作成過程で決めたこと

> 会話文の方針の**最終権威**。`docs/会話文集.md` が実データ、こちらがその根拠。
> `src/content/validate.ts` の検証ルールはこの文書から導出されている。
> 内容を変えたら検証ルールも合わせて直すこと。

## 1. 全体の構造

| 項目                | 決定                         | 理由                                                                                                          |
| ------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 総文数              | **58文**                     | 新出漢字50字＋第2段階専用の回8文                                                                              |
| 1文あたりの新出漢字 | **1字**                      | 対象漢字50字と1対1で対応させ、1日5字ペースに合わせる                                                          |
| 章構成              | **全4章**                    | 第1章10文 / 第2章15文 / 第3章16文 / 第4章17文                                                                 |
| 第1章の字数         | **10字**                     | 課金の境界(第1章まで無料)と章の切れ目を一致させ、「1章まるごと無料で体験→続きはサブスク」という導線にするため |
| 1文の長さ           | **1〜2往復**                 | 日常会話の空気が出る最小単位。短ければ飽きる前に終わる                                                        |
| 登場人数            | **2人の回と3人の回を混ぜる** | 常に3人だと単調になる                                                                                         |

### 章テーマ

| ----- | ------------ | ------ | ----------- | ------ | -------- |

| 第2章 | 一日の暮らし | 14     | 1           | 15     | 有料     |
| 第3章 | 外に出る     | 13     | 3           | 16     | 有料     |
| 第4章 | 学びと世界   | 13     | 4           | 17     | 有料     |

## 2. ストーリー方針

| 項目                 | 決定                                                             | 理由                                                                                                                                                      |
| -------------------- | ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 連続性               | **持たせない**                                                   | 連続ドラマ形式は前回を覚えていないと楽しめず、途中参加もしづらい。制作負荷も高い。「同じキャラの、別々の日常の一場面」を積み重ねる4コマ漫画的な構成にする |
| 面白さの担い手       | **会話ではなく推測クイズ**                                       | 会話は「漢字と出会う場」に徹する。会話自体で楽しませようとすると脚本力が必要になり、破綻しやすい                                                          |
| キャラの魅力の作り方 | **性格の一貫性**                                                 | ストーリーがなくても、「いつも寝ている」「天気の話から入る」といった一貫性だけで愛着は生まれる                                                            |
| 舞台設定             | **ホームステイ**(ミアがおばあちゃんの家に下宿、飼い猫の空がいる) | 3人が毎回同じ場所にいる理由が自然。ミアが日本語を質問するのも自然で、説明を会話に埋め込める。家という舞台で生活語彙が広くカバーできる                     |

## 3. キャラクターと口調

|          | ミア                         | おばあちゃん           | 空(そら)     |
| -------- | ---------------------------- | ---------------------- | ------------ |
| 役割     | 質問する側(ユーザーの分身)   | 説明する側             | 崩す側       |
| 口調     | 丁寧語(学習者らしくやや硬い) | やわらかい年配の話し方 | 単語だけ、雑 |
| 語彙領域 | 質問・学習系                 | 生活・天気・食事       | 動作・位置   |

**口調を意図的に分けている理由**: 語尾・文長・語彙が3人とも異なるため、名前を見なくても誰の発話か判別できる。特に空は単語だけの発話が許されるので、初級者向けの極端に短い文を自然に作れる。

### 空の発話ルール

- **要求・状態・存在のみを言う。挨拶や応答はしない**
  - 理由: 猫がどこまで言葉を解するのかという設定の線引きを曖昧にしないため
  - 例: 「ごはん」「ねむい」「外」はOK。「おかえり」はNG

### ミアは空に対してだけタメ口(v0.2で追加)

- 相手が猫なので丁寧語を崩せる。ミアの気を抜いた別の面が見せられる
- 学習者にとって**短く易しい文**になる
- **副次効果**: 同じ回の中で「対空=普通形」「対おばあちゃん=丁寧語」が並ぶため、文体の対比が説明なしで学べる
- **空が出る回は必ず1往復以上のやりとりを入れる**(空を受け身のオチ要員にしない)

## 4. 漢字の扱い

| 項目               | 決定                                                    | 理由                                                                                                       |
| ------------------ | ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 未習漢字の使用     | **出してよい**                                          | ふりがな＋英訳があるため読める。既習だけで縛ると不自然な文しか書けなくなる                                 |
| 未習を使わない場所 | **第2段階の演出をする漢字の周辺**と**推測クイズの出題** | 前者は「読みが変わった」ことに集中させたいため。後者は既習漢字から推測させるのが目的なので定義上ゆずれない |
| 配置表             | **第2段階の配置のみ管理**(フル配置表は作らない)         | 第2段階だけは事故ると差別化機能が壊れるため。それ以外は自由に書いてよい                                    |

### 第2段階(読みが変わる)の配置ルール

1. **訓読みを先、音読みを後**(必ずこの順)
2. **同じ章内では出さない**。最低1章分の間隔を空ける
3. 熟語の**もう一方の漢字も既習であること**が望ましい

### 例外扱いの字(3字)

| 字              | 扱い                           | 理由                                                                                                              |
| --------------- | ------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| **天**(第2章15) | 最初から音読み「てん」で教える | 訓読み「あま」がほぼ使われないため、訓→音の段階が踏めない                                                         |
| **本**(第4章49) | 最初から音読み「ほん」で教える | 同上。同じ回で「ほん」「にほん」の2用法を出し、「音読み同士で語が変わる」パターンとして扱う                       |
| **語**(第4章53) | 最初から音読み「ご」で教える   | 訓読み「かた-る」より音読みでの使用が圧倒的。同じ回で「日本語」「英語」を出し、意味の核が共通していることを見せる |

> 語を例外に加えたのは 2026-08-15。`会話文集.md` #53 の見出しが「語 — かた(る)」、
> 新出行が「語(ご)」と食い違っていたため確認し、天・本と同じ扱いに統一した。
> 見出し側の表記は会話文集の次回更新時に直す。

## 5. 第2段階の設計(全8回)

| 回  | 語     | 対象字 | 学んだ章 | ミアの反応       |
| --- | ------ | ------ | -------- | ---------------- |
| 17  | 日曜日 | 日     | 1章      | 驚く(初回)       |
| 30  | 水曜日 | 水     | 2章      | 自信を持って外す |
| 38  | 時間   | 時・間 | 2章      | 仕組みを推測する |
| 41  | 休日   | 休     | 2章      | 自分で気づく     |
| 45  | 大学   | 大・学 | 1章・4章 | 確認する         |
| 48  | 学生   | 生     | 4章      | 確認するだけ     |
| 51  | 新聞   | 聞     | 4章      | 成り立ちを教わる |
| 55  | 外国   | 外・国 | 3章・4章 | 自分で組み立てる |

**ミアの成長曲線**: 17(教わる) → 30(外す) → 41(自分で気づく) → 48(確認するだけ) と反応を変化させることで、同じ「読みが変わる」体験が繰り返しにならないようにしている。

**2字同時に第2段階を迎える回**: 38(時間)、45(大学)、55(外国)。熟語の仕組みそのものを説明できる回になる。特に45と55は**章をまたいで合流**するため、「何日も前に覚えた字が効いてくる」体験になる。

### 配置ルール2「同じ章内では出さない」の未解決点

実データでは 8回中4回が同章内になっている。

| 回  | 語   | 同章内の字  | 間隔  |
| --- | ---- | ----------- | ----- |
| 45  | 大学 | 学 #42(4章) | 3文差 |
| 48  | 学生 | 生 #43(4章) | 5文差 |
| 51  | 新聞 | 聞 #44(4章) | 7文差 |
| 55  | 外国 | 国 #54(4章) | 1文差 |

第4章は17文に新出13字＋第2段階4回を詰め込むため構造的に避けられない。
ミアの反応を「確認するだけ」に変えることで演出側から補っている(48・55)。
**検証ルールでは error にせず警告として可視化する**。ルールを緩めるかどうかは保留。

## 7. 検討したが採用しなかったこと

| 案                                         | 不採用の理由                                                                                      |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| 実在の漫画・ニュースからセリフを抽出       | 著作権リスク。ストア公開・サブスク課金と両立しない                                                |
| 連続したストーリー展開                     | 前回を覚えていないと楽しめず、途中参加もしづらい。制作負荷も高い                                  |
| 経過時間に依存する内容(「もう秋ですね」等) | ユーザーは数日かけて章を進むため古びる。※ただしルールとしては明文化せず、都度判断とする           |
| 空を章末のオチ要員にする(v0.1)             | 発言が会話に何の影響も与えず、いてもいなくても成立してしまっていた → v0.2でミアとのやりとりを追加 |
