# テーマ背景装飾 画風プロンプト定義

最終更新: 2026-08-16
用途: テーマごとの全画面背景装飾(桜のみ確定・1枚)

漢字イラストとは**用途が別物**(主役ではなく地)なので、パレットも合格ラインも別に持つ。
漢字イラスト側は `docs/画風プロンプト定義.md` を参照。

---

## 1. 確定した方向性

| 項目     | 決定                                                                       |
| -------- | -------------------------------------------------------------------------- |
| 対象     | 桜テーマのみ。ノーマル / 東京の夜景はデザイン未確定のため保留              |
| 出典     | デザイン案「春 ／ 春泥棒」(ADR-0004)                                       |
| コンセプト | 満開ではなく**散りぎわ**。花びらそのものより「落下の軌跡」を描く          |
| 枚数     | 1枚。全画面で使い回す(要件5.3)                                             |
| サイズ   | 縦長 9:19.5(1179×2556 相当)。フルブリード                                  |
| 配置先   | `assets/themes/sakura/backdrop.png`                                        |

漢字イラスト側から**2つの原則を引き継ぐ**。

- **純黒 `#000000` を使わない。** 最も濃い色でも charcoal 止まり
- **文字・漢字を明示的に排除する。** 生成AIは崩れた日本語文字を高頻度で描き込む

## 2. ベースプロンプト

```
A very pale, minimal vertical background image for a mobile app screen.

The top quarter holds a faint spring-sky wash in soft dusty blue (#C5D6E8), dissolving
into a warm off-white (#FBF4F4) by about 25% down. The remaining three quarters stay
almost empty warm off-white.

Across the canvas, three or four extremely thin near-vertical hairlines, tilted about
20 degrees from vertical, drawn in muted dusty rose (#D2839C) at very low opacity.
These are the falling paths of cherry petals — the trails, not the petals.

Five or six small cherry blossom petals, simple soft ellipses in the same muted dusty
rose, scattered sparsely near the left and right edges, never in the centre.

Overall impression: quiet, restrained, faded — the moment after the blossoms have
already fallen, not a cherry tree in full bloom. Extremely low contrast, no focal point,
large empty areas. Flat with a fine grain paper texture. Desaturated: one step less
saturated than a typical sakura theme.

--ar 9:19.5
--no text, letters, japanese characters, kanji, watermark, tree branches, tree trunk,
full cherry tree in bloom, dense petal storm, high saturation, strong contrast,
vignette, dark corners, borders, frames, centered subject, photorealistic, 3d render,
drop shadows, neon, pure black
```

### 補足

- **`--no` の要点**: `text, letters, japanese characters, kanji` は必須。
  加えて `centered subject` と `vignette, dark corners` を必ず入れる。
  中央に何か来ると漢字イラストと喧嘩し、四隅が暗いと吹き出しが沈む
- **`full cherry tree in bloom` の除外が肝**。「桜」と書くと生成AIは満開の木を描く。
  この案が欲しいのは**散った後**なので、明示的に打ち消す
- Midjourney以外(DALL-E / Imagen 等)を使う場合、`--ar` は出力サイズ指定に置き換え、
  `--no` 以降は「Do not include: ...」の自然文にする

## 3. カラーパレット(この背景専用)

| 役割                       | 色                 | HEX       |
| -------------------------- | ------------------ | --------- |
| 地                         | warm off-white     | `#FBF4F4` |
| 上部の空                   | soft dusty blue    | `#C5D6E8` |
| 花びら・落下の軌跡         | muted dusty rose   | `#D2839C` |
| 最暗色(使うとしても極薄)   | charcoal           | `#453B41` |

**4色以外を足さない。** 色数が増えるほど、上に載る本文と白い吹き出しの視認性が落ちる。
`#FBF4F4` と `#D2839C` は `src/theme/themes/sakura.ts` の `background` / `accent` と同じ値。
**背景画像とトークンで色がずれると画面が濁る**ので、片方を変えたらもう片方も直す。

---

## 4. 合格ライン(生成しただけで採用しない)

生成物は必ずシミュレータに置いて以下を確認する。1〜2で落ちたら生成をやり直す。

1. **本文が読めるか** — `#453B41` の明朝 17.5pt を、背景の一番濃い箇所の上で読めること。
   **これが本当の合格ライン**
2. **白い吹き出しが浮くか** — `#FFFFFF` の吹き出しと `#FBF4F4` の地が判別できること。
   差が小さいので潰れやすい
3. **軌跡が残るか** — opacity を下げると斜めのヘアラインから先に消える。消えたら濃度が足りない
4. **中央が空いているか** — 漢字イラストが載る画面中央に模様が来ていないこと
5. **どの画面でも破綻しないか** — 全画面固定で1枚を敷くため、会話・樹・設定のどれで見ても成立すること

---

## 5. 制作フロー

1. 上記プロンプトで3〜4枚生成し、並べて**一番「静か」なもの**を選ぶ
2. `assets/themes/sakura/backdrop.png` として配置する
3. `src/theme/themes/sakura.ts` の `backdrop` を差し替える

   ```ts
   backdrop: { source: require('@/assets/themes/sakura/backdrop.png'), opacity: 1 },
   ```

   `@/assets/*` は `tsconfig.json` の `paths` にあるが、`require()` で解決した実績が
   リポジトリにまだ無い。**TypeScript が通っても Metro が別解決する可能性がある**ので、
   このときバンドルまで通ることを確認する。通らなければ相対パスの `require` に落とす

4. 合格ライン5項目をシミュレータで確認する
5. 濃すぎる場合は**生成をやり直す前にまず `opacity` を下げる**(0.15〜0.25 が目安)。
   要件5.3 の「背景装飾は薄く敷く」はここで効かせる
